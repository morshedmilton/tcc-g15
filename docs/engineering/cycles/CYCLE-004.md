## 1. Executive Summary

Cycle 004 implements the observability, profiling, and diagnostics requirements specified in `OPP-006` (ADR-004):
1. **Bounded Session Telemetry Logging (`OPP-006` / ADR-004):** Created `TelemetryLogger` engine recording timestamps, CPU/GPU temperatures, fan RPMs, thermal modes, and AC power status in standard RFC 4180 CSV format (`%LOCALAPPDATA%\tcc-g15\telemetry\session_<YYYYMMDD_HHMMSS>.csv`).
2. **Strict Bounded Retention & Size Guard:** Enforces strict limits: max 10MB per session file (~88 continuous hours at 2s poll) and bounded rotation retaining a maximum of 5 recent sessions, guaranteeing zero unbounded disk accumulation.
3. **Tray Controls & Persistence:** Added checkable "Session telemetry logging" toggle and "Open logs directory" context actions in the system tray menu, persisting user preference under `app/telemetry_logging` in `QSettings`.
4. **Diagnostics Bug Report Integration:** Automatically bundles the most recent session `telemetry.csv` inside `bugreport-<stamp>.zip` generated by `Diagnostics.build()`, enabling instant correlation of hardware thermal throttling dynamics with system state.
5. **Fail-Safe Non-Interference Invariant (INV-1 / INV-2):** All file I/O operations are sandboxed; disk failures never interrupt fail-safe trips or the decoupled background telemetry loop.
